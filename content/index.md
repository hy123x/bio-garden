# 🌱 生物知识花园

欢迎来到我的知识花园。这里是我读研期间积累的生物学知识，用「数字花园」的方式组织——像 GitHub 托管代码一样，用 git 管理知识、用 Markdown 书写、用链接把零散的想法串成一张网。

## 三大板块

| 板块 | 内容 |
|------|------|
| 🎓 [研究生生活](./grad-life/) | 读研踩坑、学习方法、科研心态 |
| 🧪 [实验技巧](./protocols/) | 实验 protocol、操作要点、避坑指南 |
| 🧬 [基因功能](./genes/) | 研究基因的功能、通路与文献笔记 |

## 这里有什么特别

- **像 GitHub**：所有内容都是 Markdown 文件，用 git 做版本管理，每一次修改都可追溯
- **双向链接**：笔记之间用 `[[链接]]` 互相引用，知识连成网络
- **知识图谱**：右侧图谱视图，可视化笔记之间的关联
- **全文搜索**：右上角搜索任意关键词

## 开始探索

点左侧目录树，或右上角搜索。也可以在右侧图谱里随便点一个节点，看看会走到哪里。
